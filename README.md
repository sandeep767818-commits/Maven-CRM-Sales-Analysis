# Maven CRM Sales Opportunities Analysis 
## Project Overview

This project analyses a CRM sales pipeline dataset to understand deal outcomes, product performance, sales agent performance, and revenue trends.

The project follows an end-to-end data analytics workflow using Excel, MySQL, and Power BI.

## Tools Used
- **Microsoft Excel:** PivotTables, charts, KPI cards, and slicers
 
- **MySQL:** Data cleaning, data validation, aggregations, joins, CTEs, and window functions
  
- **Power BI:** Interactive dashboard, KPI cards, charts, and slicers
 
## Dataset

The dataset contains 8,800 sales opportunities along with information about products, sales agents, accounts, and sales teams.

## Analysis Performed
- Analysed deal stages, including Won, Lost, Engaging, and Prospecting
  
- Calculated the win rate using closed opportunities
  
- Compared product performance and won revenue
 
- Analysed sales agent and regional performance
  
- Examined monthly and quarterly revenue trends
 
- Checked missing values, duplicate opportunity IDs, and product name inconsistencies
 
## Key Findings
- **Total opportunities analysed:** 8,800
  
- **Won deals:** 4,238
  
- **Win rate:** approximately 63% among closed opportunities
  
- Compared products, sales agents, and revenue trends to identify performance patterns
